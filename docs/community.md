# Community & ecosystems

This project is **local-first** and MIT-licensed. Community surfaces are optional and do not change the formal delivery path (`bin/upm make` + local export).

## Socialistic (optional try-it)

A README badge may link to a Socialistic-hosted try-it skill so readers can run a session without cloning. Traces can help improve SKILL wording.

- Badge / try: see README top
- Skill page: https://socialistic.ai/zh/skill/ultimate-ppt-master-skill-99fe3d
- **Not** a formal delivery channel; quality gates and private data handling still assume local `upm`.

## Open Design and similar plugin hosts

Invitations to package Ultimate PPT Master as a plugin (e.g. Open Design) are welcome as **community work**:

- Keep MIT attribution and do not claim magazine Web Deck or Kimi as GA.
- Prefer wrapping `bin/upm make` / Preserve Edit rather than re-implementing DeckIR.
- Official in-repo Open Design plugin package is **not** maintained at this time; open a PR with a minimal manifest if you want first-party consideration later.
